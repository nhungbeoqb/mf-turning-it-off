## The line

One funny line from a hopeless tech support agent to a desperate customer:

> Yours died, mine just died too — let's both turn it off and on again, on three, and whoever comes back first wins.

The agent's own headset dies mid-call, so the classic "turn it off and on again" becomes a shared predicament — and a race. The humour is the agent's cheerful uselessness, never the customer.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to `$OUTPUT_DIR/entry.txt` (default `/output`), after a gate self-check mirroring the sealed scorer: UTF-8 text of 1 to 199 characters, not only whitespace, a single line, and a read-back verification that what was written is exactly the line.

Run it:

```sh
OUTPUT_DIR=/tmp/turning-it-off-out python3 main.py
```
